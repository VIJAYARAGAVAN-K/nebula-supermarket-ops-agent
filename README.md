# Nebula Supermarket Operations Agent

An AI-powered conversational agent designed to manage day-to-day operations of a small Indian supermarket / kirana store through Telegram.

## Project Status

# Under Development

## Planned Capabilities

- Natural-language supermarket operations
- Inventory and stock management
- Multi-turn billing
- GST calculation and tax breakdown
- Customer Khata / credit management
- Stock and sales analysis
- PDF invoice generation
- PPTX business-analysis reports
- Persistent store preferences
- Agent-based tool orchestration

## Technology

- Python
- Telegram Bot API
- LLM-based Agent
- SQLite
- PDF generation
- PPTX generation
